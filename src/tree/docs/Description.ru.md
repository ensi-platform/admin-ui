Дерево для вложенных строк: шеврон раскрывает ветку, нажатие на строку выбирает её.

```tsx
import { Tree } from '@ensi-platform/admin-ui/tree';
```

## Когда использовать

- иерархия, где ветки раскрываются, а строка выбирается отдельно
- один или несколько выбранных узлов
- не для плоского меню — см. `MenuList`
- не для короткого списка значений — см. `Select`

## API (кратко)

| Prop                  | Значения                                | По умолчанию | Описание                                                                                                                              |
| --------------------- | --------------------------------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| `items`               | `{ id, label, children?, disabled? }[]` | —            | узлы. Пустой `children` или его отсутствие — лист. `disabled` блокирует выбор и раскрытие этого узла                                  |
| `aria-label`          | `string`                                | —            | доступное имя. Видимой подписи у дерева нет                                                                                           |
| `selectionMode`       | `none` \| `single` \| `multiple`        | `single`     | режим выбора. В `single` повторное нажатие не снимает строку. В `multiple` повторное нажатие снимает её. Пустой набор ключей допустим |
| `selectedKeys`        | `Selection`                             | —            | выбранные ключи                                                                                                                       |
| `defaultSelectedKeys` | `Selection`                             | —            | начальный выбор без внешнего состояния                                                                                                |
| `onSelectionChange`   | `(keys) => void`                        | —            | обработчик выбора. Не вызывается при `disabled` и `readOnly`                                                                          |
| `expandedKeys`        | `Iterable<Key>`                         | —            | раскрытые ветки                                                                                                                       |
| `defaultExpandedKeys` | `Iterable<Key>`                         | —            | начальное раскрытие без внешнего состояния                                                                                            |
| `onExpandedChange`    | `(keys) => void`                        | —            | обработчик раскрытия                                                                                                                  |
| `disabled`            | `boolean`                               | `false`      | нельзя выбрать и раскрыть ни один узел. Если задан вместе с `readOnly`, побеждает он                                                  |
| `readOnly`            | `boolean`                               | `false`      | выбор виден и не меняется, ветки раскрываются                                                                                         |
| `dataTestId`          | `string`                                | —            | атрибут `data-test-id`                                                                                                                |
