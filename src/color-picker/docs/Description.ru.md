Палитра: площадка насыщенности, ползунок оттенка и готовые цвета. Поле с кодом — `ColorField`.

```tsx
import { ColorPicker } from '@ensi-platform/admin-ui/color-picker';
```

## Когда использовать

- цвет выбирают на площадке, без строки кода
- короткий набор допустимых цветов рядом с площадкой — проп `presets`
- код нужно вписать или показать свотч в поле — см. `ColorField`

## API (кратко)

| Prop                 | Значения   | По умолчанию | Описание                                                                                     |
| -------------------- | ---------- | ------------ | -------------------------------------------------------------------------------------------- |
| `value` / `onChange` | `string`   | —            | `#rrggbb`. Пустая строка показывает серый черновик и не публикуется, пока палитру не тронули |
| `defaultValue`       | `string`   | `''`         | начальное значение без внешнего состояния                                                    |
| `onPreview`          | `function` | —            | живой `#rrggbb`, пока указатель нажат. Это не публикация                                     |
| `presets`            | `string[]` | —            | готовые цвета. Неразборчивые строки отбрасываются                                            |
| `hue`                | `number`   | —            | оттенок серого цвета в градусах. Поле хранит его между открытиями панели                     |
| `onHueChange`        | `function` | —            | новый оттенок после движения по палитре. Пара к `hue`                                        |
| `disabled`           | `boolean`  | `false`      | недоступна                                                                                   |
| `dataTestId`         | `string`   | —            | атрибут `data-test-id` для тестов                                                            |

Перетаскивание публикует цвет, когда указатель отпущен. Стрелки на ползунке оттенка публикуют цвет на каждый шаг. Первое касание оттенка у пустого значения публикует серый `#808080`.
