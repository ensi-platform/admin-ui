Поле цвета: свотч открывает палитру, рядом код в виде `#rrggbb`.

```tsx
import { ColorPicker, FormColorPicker } from '@ensi-platform/admin-ui/color-picker';
```

## Когда использовать

- один непрозрачный цвет: шильд, статус, атрибут товара
- код уже известен — его можно вписать, не открывая палитру
- короткий список допустимых цветов — проп `presets`
- период, дата, время — см. `DatePicker` и `TimeField`

## API (кратко)

### ColorPicker

| Prop                 | Значения             | По умолчанию | Описание                                                                 |
| -------------------- | -------------------- | ------------ | ------------------------------------------------------------------------ |
| `value` / `onChange` | `string`             | —            | `''` или `#rrggbb`. Объект цвета наружу не отдаётся                      |
| `defaultValue`       | `string`             | `''`         | начальное значение без внешнего состояния                                |
| `presets`            | `string[]`           | —            | готовые цвета в панели. Неразборчивые строки отбрасываются               |
| `clear`              | `boolean`            | `false`      | кнопка очистки                                                           |
| `size`               | `sm` \| `md` \| `lg` | `md`         | размер                                                                   |
| `variant`            | `primary`            | `primary`    | визуальный вариант                                                       |
| `invalid`            | `boolean`            | `false`      | ошибка. Незнакомая строка в `value` тоже помечает поле                   |
| `disabled`           | `boolean`            | `false`      | недоступен                                                               |
| `block`              | `boolean`            | `true`       | на всю ширину                                                            |
| `dataTestId`         | `string`             | —            | атрибут `data-test-id` для тестов                                        |

Шесть цифр публикуются сразу. Три цифры (`#abc`) разворачиваются в `#aabbcc` на blur или Enter. Enter не отправляет форму. Перетаскивание по площадке публикует цвет в конце жеста, стрелки на ползунке оттенка — на каждый шаг.
