Хуки пакета: значение с прошлого рендера и колбэк после полного закрытия оверлея.

```tsx
import { useOverlayExitComplete, usePrevious } from '@ensi-platform/admin-ui/hooks';
```

## Когда использовать

- сохранить значение с прошлого рендера
- вызвать код, когда оверлей уже закрыт, в том числе после анимации выхода
- debounce — в `usehooks-ts`

## API (кратко)

### `usePrevious`

| Аргумент       | Значения | По умолчанию | Описание                                |
| -------------- | -------- | ------------ | --------------------------------------- |
| `value`        | `T`      | —            | текущее значение                        |
| `initialValue` | `T`      | —            | значение до первого обновления          |

Возвращает значение прошлого рендера (на первом — `initialValue`).

### `useOverlayExitComplete`

| Аргумент         | Значения     | По умолчанию | Описание                                                         |
| ---------------- | ------------ | ------------ | ---------------------------------------------------------------- |
| `open`           | `boolean`    | —            | оверлей открыт                                                   |
| `isExiting`      | `boolean`    | —            | идёт анимация выхода                                             |
| `onExitComplete` | `() => void` | —            | один раз после полного закрытия и при размонтировании во время выхода |
