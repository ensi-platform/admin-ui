Ряд или колонка с зазором: заголовок и кнопки, или несколько блоков друг под другом.

```tsx
import { FlexLayout } from '@ensi-platform/admin-ui/flex-layout';
```

## Когда использовать

- заголовок страницы и кнопки в одной строке
- несколько кнопок рядом
- колонка блоков, когда равные колонки не нужны

Равные колонки полей — `GridLayout`.

## API (кратко)

| Prop         | Значения                                      | По умолчанию | Описание                       |
| ------------ | --------------------------------------------- | ------------ | ------------------------------ |
| `direction`  | `row` \| `column`                             | `row`        | ось                            |
| `gap`        | `0` \| `4` \| `8` \| `12` \| `16` \| … \| `64` | `16`         | зазор, шаг шкалы отступов      |
| `align`      | `start` \| `center` \| `end` \| `stretch`     | `stretch`    | выравнивание по поперечной оси |
| `justify`    | `start` \| `center` \| `end` \| `between`     | `start`      | распределение по главной оси   |
| `wrap`       | `boolean`                                     | `false`      | перенос на следующую строку    |
| `hidden`     | `boolean`                                     | `false`      | убирает ряд из вёрстки         |
| `dataTestId` | `string`                                      | —            | атрибут `data-test-id` для тестов |

`FlexLayout.Item` `grow` забирает свободное место на главной оси.
