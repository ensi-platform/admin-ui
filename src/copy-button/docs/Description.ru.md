Кнопка-ссылка: показывает текст и копирует его.

```tsx
import { CopyButton } from '@ensi-platform/admin-ui/copy-button';
```

## Когда использовать

- короткий идентификатор, который нужно скопировать: номер заказа, код, артикул
- текст остаётся видимым
- подсказка на наведении — «Копировать», после успеха — что именно скопировано, при ошибке — что не вышло

Обычное действие без копирования — `Button` или `Link`.

## API (кратко)

| Prop         | Значения   | По умолчанию | Описание                                      |
| ------------ | ---------- | ------------ | --------------------------------------------- |
| `children`   | `string`   | —            | текст на кнопке и значение для буфера обмена |
| `timeout`    | `number`   | `1000`       | сколько держать подсказку успеха или ошибки, мс |
| `dataTestId` | `string`   | —            | атрибут `data-test-id` для тестов             |

Подписи берутся из `AdminUiProvider`: `labels.copy`, `labels.copied` (`{value}` — скопированный текст), `labels.copyFailed`.
