Статусный круг с инициалами или фото пользователя.

```tsx
import { Avatar } from '@ensi-platform/admin-ui/avatar';
```

## Когда использовать

- аватар в сайдбаре, хедере, списках
- инициалы из `name` / `initials` или фото через `src`
- не для статусных меток — см. `Badge`

## API (кратко)

| Prop         | Значения             | По умолчанию | Описание                                     |
| ------------ | -------------------- | ------------ | -------------------------------------------- |
| `size`       | `sm` \| `md` \| `lg` | `md`         | размер                                       |
| `variant`    | `primary`            | `primary`    | визуальный вариант                           |
| `name`       | `string`             | —            | имя (a11y + источник инициалов)              |
| `initials`   | `string`             | из `name`    | явные инициалы                               |
| `src`        | `string`             | —            | URL изображения                              |
| `children`   | `ReactNode`          | —            | кастомный контент (поверх `src` / инициалов) |
| `dataTestId` | `string`             | —            | атрибут `data-test-id`                       |
