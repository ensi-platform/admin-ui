Однострочное поле, которое приводит ввод к маске `IMask`. Сама маска передаётся снаружи в `opts`.

```tsx
import { Mask, FormMask } from '@ensi-platform/admin-ui/mask';
```

## Когда использовать

- телефон, ИНН, код и другой текст, формат которого задаёт приложение
- дата — см. `DatePicker`
- число — см. `NumberInput`
- свободный текст — см. `Input`

## API (кратко)

В `value` и `onChange` уходит строка как в поле, вместе с символами маски. Пустое поле — `''`. Незавершённый ввод уходит сразу. Если маска меняет переданный `value`, `onChange` вызывается один раз с приведённой строкой. Пока родитель не запишет её обратно, на экране остаётся `value`.

`opts` передавайте тем же объектом между отрисовками: константа снаружи или `useMemo`. Новый объект на каждую отрисовку заставляет `IMask` обновлять маску заново.

### Mask

| Prop         | Значения             | По умолчанию | Описание                                      |
| ------------ | -------------------- | ------------ | --------------------------------------------- |
| `opts`       | `FactoryOpts`        | —            | настройки IMask (`mask`, `blocks`, `prepare`) |
| `size`       | `sm` \| `md` \| `lg` | `md`         | размер; внутри Field наследует `Field.size`   |
| `invalid`    | `boolean`            | `false`      | ошибка                                        |
| `disabled`   | `boolean`            | `false`      | недоступен                                    |
| `readOnly`   | `boolean`            | `false`      | видно и можно скопировать, изменить нельзя    |
| `clear`      | `boolean`            | `false`      | кнопка очистки → `onChange` с `''`            |
| `dataTestId` | `string`             | —            | атрибут `data-test-id` для тестов             |

Хром совпадает с `Input`. Без `as`.

### FormMask

| Prop         | Значения             | По умолчанию | Описание                                   |
| ------------ | -------------------- | ------------ | ------------------------------------------ |
| `name`       | `string`             | —            | имя поля в `Form`                          |
| `opts`       | `FactoryOpts`        | —            | настройки IMask                            |
| `label`      | `ReactNode`          | —            | подпись (`Field.Label`)                    |
| `hint`       | `ReactNode`          | —            | подсказка                                  |
| `clear`      | `boolean`            | —            | кнопка очистки                             |
| `size`       | `sm` \| `md` \| `lg` | `md`         | размер (на Field)                          |
| `disabled`   | `boolean`            | —            | недоступен                                 |
| `readOnly`   | `boolean`            | —            | видно и можно скопировать, изменить нельзя |
| `dataTestId` | `string`             | —            | атрибут `data-test-id` для тестов          |

value / onChange / onBlur / валидность — из `Form`.
