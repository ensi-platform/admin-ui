CSS-переменные холста админки. Это не компонент. Подключаются один раз; примитивы читают свои `--aui-{name}-*` и этот файл не импортируют.

```tsx
import '@ensi-platform/admin-ui/tokens';
```

## Когда использовать

- точка входа приложения, до любого экрана
- цвет страницы и подложки в своей вёрстке
- не для оформления контрола — оно остаётся у примитива (`Button`, `Input`, …) и его `cssVariables.ts`

## API (кратко)

Тема — `data-theme="light" | "dark"` на `document.documentElement`. Светлые значения на `:root`, тёмные переопределяют те же имена. Компоненты на тему не ветвятся.

В своей вёрстке можно только это:

| Токен | Роль |
| --- | --- |
| `--aui-page-bg-primary` | подложка страницы |
| `--aui-page-fg-primary` | текст страницы |
| `--aui-page-fg-muted` | вторичный текст |
| `--aui-page-fg-link` | текст ссылки (подчёркивание; тот же, что текст страницы) |
| `--aui-surface-bg-primary` | заливка поля / приподнятой подложки |
| `--aui-surface-bg-muted` | вторичная кнопка, тег, наведение |
| `--aui-surface-bg-elevated` | приподнятая подложка |
| `--aui-surface-border-primary` | обводка зоны, если у зоны нет заливки |

Шкалы (`--aui-neutral-*`, `--aui-grey-*`, `--aui-red-*`, `--aui-radius-*`, `--aui-spacing-*`) в CSS приложения не использовать. Слои экрана и роли цветов — `docs/design-language.md`.
