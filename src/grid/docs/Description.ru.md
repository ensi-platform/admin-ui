Сетка для полей и для разреза колонок.

```tsx
import { Grid } from '@ensi-platform/admin-ui/grid';
```

## Когда использовать

- поля секции в две или три колонки
- пункт на всю ширину сетки (`col="full"`)
- разрез «контент и боковая колонка», если передать свои дорожки в `cols`

Сетка фильтров списка — `Filters.Grid`.

## API (кратко)

| Prop         | Значения                                      | По умолчанию | Описание                          |
| ------------ | --------------------------------------------- | ------------ | --------------------------------- |
| `cols`       | `number` \| массив дорожек                    | —            | колонки                           |
| `gap`        | `0` \| `4` \| `8` \| `12` \| `16` \| … \| `64` | `16`         | зазор, шаг шкалы отступов         |
| `col`        | `number` \| `full`                            | —            | span, если сетка лежит в другой   |
| `align`      | `start` \| `center` \| `end` \| `stretch`     | `stretch`    | выравнивание по поперечной оси    |
| `hidden`     | `boolean`                                     | `false`      | убирает сетку из вёрстки          |
| `dataTestId` | `string`                                      | —            | атрибут `data-test-id` для тестов |

`Grid.Item`: `col` — сколько колонок занять. `full` тянется на всю сетку. Число в `cols` даёт равные колонки `minmax(0, 1fr)`. Число внутри списка дорожек — это `Nfr`, строка пишется как есть (`minmax(0, 1fr)`).
