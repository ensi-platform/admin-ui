Настройки видимости и порядка пунктов: фильтры списка или колонки таблицы. Открывается отдельно от `Filters` и `Table`.

```tsx
import { ArrangementSettings } from '@ensi-platform/admin-ui/arrangement-settings';
```

## Когда использовать

- пользователь выбирает, какие фильтры или колонки видны и в каком порядке
- значения фильтров остаются в `Filters`, колонки остаются в `Table`

## API (кратко)

| Prop           | Значения                          | По умолчанию | Описание                                         |
| -------------- | --------------------------------- | ------------ | ------------------------------------------------ |
| `open`         | `boolean`                         | —            | открыт ли `Drawer`                               |
| `onOpenChange` | `(open: boolean) => void`         | —            | смена открытия; отмена и закрытие без сохранения |
| `title`        | `string`                          | —            | заголовок                                        |
| `placement`    | `left` \| `right`                 | `left`       | сторона, с которой выезжает `Drawer`             |
| `items`        | `{ id: string; label: string }[]` | —            | все пункты, включая скрытые                      |
| `value`        | `string[]`                        | —            | видимые id в текущем порядке                     |
| `onSave`       | `(value: string[]) => void`       | —            | сохранить черновик                               |
| `dataTestId`   | `string`                          | —            | атрибут `data-test-id` для тестов                |

Черновик копируется при открытии. Строку перетаскивают целиком, вместе с боковой подложкой, двигается только она: чекбокс показывает пункт и не входит в перетаскивание. Между строками видна линия вставки, под курсором — приподнятая копия строки. Скрытый пункт остаётся в списке. В сохранение попадают только отмеченные id, в порядке списка.
