Текстовая ссылка для переходов в интерфейсе.

```tsx
import { Link } from '@ensi-platform/admin-ui/link';
```

## Когда использовать

- переход по тексту внутри контента (таблица, форма, подсказка)
- inline-навигация без вида кнопки
- вид кнопки с переходом — см. `Button` с `as`

## API (кратко)

| Prop         | Значения                                                                              | По умолчанию | Описание                                 |
| ------------ | ------------------------------------------------------------------------------------- | ------------ | ---------------------------------------- |
| `as`         | тег или компонент                                                                     | `a`          | корень; для SPA обычно компонент роутера |
| `typography` | `bodyXs` \| `bodyS` \| `bodySTight` \| `bodyM` \| `bodyL` \| `headingM` \| `headingL` | `bodyS`      | роль из `@ds/typography`                 |
| `dataTestId` | `string`                                                                              | —            | атрибут `data-test-id` для тестов        |

Обычные атрибуты ссылки (`href`, `target`, `rel`, …) и пропы выбранного корня принимаются через полиморфизм. Обёртка с роутером приложения — в **Getting started**.
