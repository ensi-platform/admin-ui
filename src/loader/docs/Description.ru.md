Локальная вуаль со спиннером поверх контента на время загрузки.

```tsx
import { Loader } from '@ensi-platform/admin-ui/loader';
```

## Когда использовать

- блокировать клики по списку / карточке / форме, пока грузятся данные
- повторный запрос поверх уже показанного UI (дети не размонтируются)

## API (кратко)

| Prop | Значения | По умолчанию | Описание |
| --- | --- | --- | --- |
| `size` | `sm` \| `md` \| `lg` | `md` | размер спиннера |
| `active` | `boolean` | `false` | показать вуаль и спиннер |
| `children` | `ReactNode` | — | контент под оверлеем |
| `dataTestId` | `string` | — | атрибут `data-test-id` для тестов |

Обычные атрибуты `div` (`className`, …) принимаются.
