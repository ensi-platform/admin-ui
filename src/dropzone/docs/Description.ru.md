Поле для выбора файлов: клик, перетаскивание и вставка из буфера.

```tsx
import { Dropzone, FormDropzone } from '@ensi-platform/admin-ui/dropzone';
```

## Когда использовать

- вложения к сущности (несколько файлов, порядок важен)
- одно изображение (логотип, аватар) — `maxFiles={1}` и `accept` только с `image/`
- импорт файла — см. тот же примитив с `maxFiles={1}`

## API (кратко)

Значение — массив `{ id, name, size, type, file?, url? }`. Новый файл получает `id` и `file`. Файл с сервера приходит с `id` и `url`. Текст отказа в значение не входит. Сверху `title` и `description`, затем большая зона с иконкой, под ней файлы. Типы и предел одного файла пишутся в зоне, `hint` дописывается в ту же строку. `validate` возвращает причину отказа или ничего: файл с причиной в список не попадает. Число и общий размер — строка под зоной. На пределе числа зона говорит, что лимит достигнут, и файл не добавляется. `maxFiles={1}` зону не закрывает: новый файл заменяет текущий. `onChange` вызывается раньше `onRemove` у файла, который ушёл. `layout="grid"` показывает карточки: у изображения превью, у остальных иконка типа. Повтор и удаление — кнопки в строке. `upload` отправляет файл сразу; в значение он попадает после ответа, уже с `id` и `url`, без `file`.

### Dropzone

| Prop | Значения | По умолчанию | Описание |
| --- | --- | --- | --- |
| `title` | `ReactNode` | — | заголовок над зоной |
| `description` | `ReactNode` | — | текст под заголовком |
| `hint` | `ReactNode` | — | своё условие в строке зоны, после типов и предела файла |
| `validate` | `(file) => string \| null \| Promise<...>` | — | пусто оставляет файл, строка — причина отказа |
| `value` | `IDropzoneFile[]` | — | выбранные файлы; без пропа список хранится внутри |
| `defaultValue` | `IDropzoneFile[]` | — | начальный список, если нет `value` |
| `onChange` | `(files) => void` | — | следующий список |
| `onRemove` | `(file) => void` | — | после удаления, в аргументе файл с `id` |
| `renderAction` | `(file) => ReactNode` | — | своя кнопка рядом с удалением; для неё есть `Dropzone.Action` с `icon` и `hidden` |
| `accept` | `Record<mime, string[]>` | — | допустимые типы |
| `maxSize` | `number` | — | максимум байт на файл |
| `maxTotalSize` | `number` | — | максимум байт на сумму списка и ещё грузящихся файлов |
| `maxFiles` | `number` | — | предел числа; `1` заменяет текущий файл |
| `maxFileNameLength` | `number` | — | максимум длины имени |
| `paste` | `boolean` | `false` | вставка в сфокусированную зону |
| `loading` | `boolean` | `false` | зона на месте и не принимает файлы; вместо списка скелетон |
| `layout` | `list` \| `grid` | `list` | строки или карточки; выбирает `list` и `item`, если их не передали |
| `list` | `ComponentType<IFileListProps>` | из `layout` | своя реализация списка |
| `item` | `ComponentType<IDropzoneItem>` | из `layout` | реализация элемента, её получает список |
| `upload` | `(file, { onProgress, signal }) => Promise<{ id, url }>` | — | отправка сразу; `onProgress` двигает полосу, `signal` отменяет строку |
| `disabled` | `boolean \| { add?, remove?, reorder? }` | `false` | `true` выключает добавление, удаление и порядок. В объекте выключается только ключ со значением `true`; кнопка удаления остаётся на месте |
| `invalid` | `boolean` | `false` | ошибка поля |
| `size` | `sm` \| `md` \| `lg` | `md` | размер; внутри Field наследует `Field.size` |
| `dataTestId` | `string` | — | атрибут `data-test-id` |

Отклонённый файл в список не попадает. Подходящие файлы из той же порции добавляются. Причина — строка под полем; следующая порция без отказов её убирает. Клик по строке добавляет её к выделению, повторный клик снимает только её. Выделение есть, если файлов больше одного и удаление не выключено. Мышью строка тянется за любую область, кроме кнопок; клик по ней выделяет. Ручка остаётся для клавиатуры и сенсорного экрана. Сброс подсвечивает всю строку под курсором, и файл встаёт на её место. Размер стоит под именем. Пока есть выделение, на месте подсказки панель: счётчик слева и icon-кнопки справа — выбрать все и удалить выбранные. «Выбрать все» скрыта, когда выбраны все. Снятие — повторный клик по строке, Escape или клик мимо списка; клавиши Delete, Backspace и Escape работают, только пока фокус внутри этой дропзоны. На сенсорном экране тап добавляет и убирает строку.  Пока файл грузится, на строке «Отменить»: строка исчезает, `onRemove` не вызывается. Без `onProgress` полоса без числа. Ошибка загрузки остаётся на строке вместо размера: текст отказа, а без текста — общая подпись. Её можно повторить или сбросить.

Без `as`.

### FormDropzone

| Prop | Значения | По умолчанию | Описание |
| --- | --- | --- | --- |
| `name` | `string` | — | имя поля в `Form` |
| `label` | `ReactNode` | — | подпись (`Field.Label`) |
| `hint` | `ReactNode` | — | подсказка |
| `size` | `sm` \| `md` \| `lg` | `md` | размер (на Field) |
| `disabled` | `boolean \| { add?, remove?, reorder? }` | — | как у Dropzone; `true` ещё блокирует Field |
| `accept` | `Record<mime, string[]>` | — | допустимые типы |
| `maxSize` | `number` | — | максимум байт на файл |
| `maxTotalSize` | `number` | — | максимум байт на сумму |
| `maxFiles` | `number` | — | предел числа; `1` заменяет файл |
| `maxFileNameLength` | `number` | — | максимум длины имени |
| `paste` | `boolean` | `false` | вставка |
| `loading` | `boolean` | `false` | скелетон вместо списка |
| `layout` | `list` \| `grid` | `list` | строки или карточки |
| `upload` | `(file, { onProgress, signal }) => Promise<{ id, url }>` | — | отправка сразу |
| `validate` | `(file) => string \| null \| Promise<...>` | — | пусто оставляет файл, строка — причина отказа |
| `onRemove` | `(file) => void` | — | после удаления |
| `renderAction` | `(file) => ReactNode` | — | своя кнопка, `Dropzone.Action` |
| `dataTestId` | `string` | — | атрибут `data-test-id` |

Ошибка схемы и строка отказа стоят в одном месте под полем. Отказ файла не пишет ошибку в форму: отправка остаётся возможной, если схема довольна уже лежащими файлами. Пока файл грузится или строка с ошибкой загрузки ещё в списке, отправка блокируется.
