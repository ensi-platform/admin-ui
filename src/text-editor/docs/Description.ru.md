Визуальный редактор HTML: тулбар собирает разметку, кнопка «Исходник» показывает ту же строку в `TextArea`.

## Когда использовать

- текст страницы, уведомления или SEO, который уезжает на бэк строкой HTML
- обычный многострочный текст без разметки — см. `TextArea`
- файл картинки — только если экран передал `uploadImage`; иначе картинка задаётся адресом

## API (кратко)

### TextEditor

| Prop | Значения | По умолчанию | Описание |
| --- | --- | --- | --- |
| `value` | `string` | — | HTML; пустой документ — `''` |
| `defaultValue` | `string` | `''` | начальный HTML без внешнего состояния |
| `onChange` | `(value: string) => void` | — | следующая строка HTML |
| `size` | `sm` \| `md` \| `lg` | `md` | размер; внутри `Field` наследует `Field.size` |
| `invalid` | `boolean` | `false` | ошибка |
| `disabled` | `boolean` | `false` | недоступен |
| `readOnly` | `boolean` | `false` | видно, изменить нельзя |
| `block` | `boolean` | `true` | на всю ширину родителя |
| `fontFamilies` | `string[]` | системные 5 | подменяет меню шрифта |
| `uploadImage` | `(file: File) => Promise<string>` | — | загрузка файла, в редактор уходит адрес |
| `maxLength` | `number` | — | потолок видимого текста, дальше ввод не растёт |
| `dataTestId` | `string` | — | атрибут `data-test-id` |

Тулбар группами: история, меню абзаца и `h1`–`h4`, шрифт, размер, интервал, начертание, индексы, цвет, выравнивание, списки и задачи, отступ, цитата, код, линия, ссылка, якорь, картинка, видео (`iframe`), эмодзи, таблица. На выделении всплывают только инлайн-команды. Вёрстка вне схемы (`div`, `section`, `script`, `style`) — чип «HTML»: в страницу админки не исполняется, наружу уходит исходный кусок. Чистку HTML делает витрина, не редактор.
