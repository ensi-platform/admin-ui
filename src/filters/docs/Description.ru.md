Секция фильтров листинга: сетка полей разной ширины и подвал с кнопками.

```tsx
import { Filters } from '@ensi-platform/admin-ui/filters';
```

## Когда использовать

- форма фильтров списка на странице
- дата и диапазон занимают больше колонок, чем короткое поле
- видимость и порядок полей — `ArrangementSettings`, не эта секция

## API (кратко)

| Prop         | Значения | По умолчанию | Описание                          |
| ------------ | -------- | ------------ | --------------------------------- |
| `dataTestId` | `string` | —            | атрибут `data-test-id` для тестов |

Слоты: `Grid` / `Cell` / `Footer`. `Form` и контролы снаружи.

### Grid

| Prop         | Значения                 | По умолчанию | Описание                                                       |
| ------------ | ------------------------ | ------------ | -------------------------------------------------------------- |
| `columns`    | `number`                 | `4`          | число равных колонок; страница задаёт сама, брейкпоинтов нет   |
| `span`       | `Record<string, number>` | —            | вид поля → колонки; неизвестный вид берёт `default`, иначе `1` |
| `dataTestId` | `string`                 | —            | атрибут `data-test-id` для тестов                              |

Ширина ячейки обрезается до `1…columns`.

### Cell

| Prop         | Значения | По умолчанию | Описание                          |
| ------------ | -------- | ------------ | --------------------------------- |
| `kind`       | `string` | —            | ключ в `span`                     |
| `dataTestId` | `string` | —            | атрибут `data-test-id` для тестов |

### Footer

Ряд кнопок: слева и справа за счёт `space-between`. Кнопки кладёт страница.
