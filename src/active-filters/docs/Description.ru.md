Ряд активных фильтров над списком: чипы и ссылка «Очистить».

```tsx
import { ActiveFilters } from '@ensi-platform/admin-ui/active-filters';
```

## Когда использовать

- над таблицей видно, какие фильтры уже применены
- одно значение — отдельный чип, его можно снять крестиком
- несколько значений одного поля — один чип со счётчиком и тем же списком, что в фильтре колонки
- не форма полей — см. `Filters`
- не статус сущности — см. `Badge`

## API (кратко)

### ActiveFilters

| Prop         | Значения     | По умолчанию | Описание                                |
| ------------ | ------------ | ------------ | --------------------------------------- |
| `children`   | `ReactNode`  | —            | чипы; пустой ряд не рисуется            |
| `onClear`    | `() => void` | —            | ссылка «Очистить»; без пропа ссылки нет |
| `dataTestId` | `string`     | —            | атрибут `data-test-id` для тестов       |

Текст ссылки — `clearFilters` из `AdminUiProvider`.

### Item

| Prop         | Значения     | По умолчанию | Описание                            |
| ------------ | ------------ | ------------ | ----------------------------------- |
| `children`   | `ReactNode`  | —            | подпись, например «Категория: мясо» |
| `onRemove`   | `() => void` | —            | крестик                             |
| `disabled`   | `boolean`    | `false`      | отключает чип и крестик             |
| `dataTestId` | `string`     | —            | атрибут `data-test-id` для тестов   |

Чип — `Tag` размера `md`.

### Group

| Prop         | Значения    | По умолчанию | Описание                                           |
| ------------ | ----------- | ------------ | -------------------------------------------------- |
| `label`      | `string`    | —            | имя поля перед счётчиком                           |
| `count`      | `number`    | —            | сколько значений выбрано                           |
| `children`   | `ReactNode` | —            | список внутри дропа, тот же, что в фильтре колонки |
| `onRemove`   | `() => void` | —           | крестик справа; снимает всю группу                 |
| `scroll`     | `auto` \| `virtual` | `auto` | `auto` — скролл дропа; `virtual` — скролл у списка внутри (`SuggestChecklist`) |
| `dataTestId` | `string`    | —            | атрибут `data-test-id` для тестов                  |

Чип выглядит как «Категории: 5» и открывает `Popover`. Сортировки колонки в этом дропе нет. Свёртку выбирает страница: нет настройки или значение одно — несколько `Item`.
